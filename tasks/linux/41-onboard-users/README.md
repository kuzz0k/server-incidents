# linux-41 · Завести пользователей по списку

**Уровень:** Junior · **Тема:** Linux / пользователи, bash · **Время:** ~25 мин

## Легенда
HR прислал список новичков `/srv/onboarding/users.csv`
(`login,full_name,groups,shell`; группы через `;`). Заводить руками долго и с ошибками:
нужен скрипт, который можно запускать при каждом новом списке.

## Задача
Напиши `/usr/local/bin/onboard-users.sh <csv>`:
1. Пропускает заголовок и пустые строки.
2. Создаёт недостающие группы и пользователей с домашним каталогом, полным именем (GECOS) и shell.
   Если указанного shell нет в `/etc/shells`, ставит `/bin/bash`.
3. Добавляет пользователя во все его группы.
4. Новому пользователю задаёт **случайный** пароль, который нужно сменить при первом входе,
   и дописывает `login:пароль` в `/root/onboarding/passwords.txt` (права только для root).
5. **Идемпотентен:** повторный запуск завершается успешно, не меняет пароли существующих
   пользователей и не дублирует строки в `passwords.txt`.

## Критерии готовности (что проверяет check)
Check запускает скрипт дважды и проверяет пользователей, группы, shell, GECOS, требование смены
пароля, совпадение паролей из файла с реальными и права на `passwords.txt`.
