# linux-30 · Написать скрипт бэкапа с ротацией

**Уровень:** Junior/Middle · **Тема:** Linux / bash · **Время:** ~30 мин

## Легенда
Классическое задание на собеседовании: «напиши скрипт бэкапа». Данные приложения лежат в
`/srv/app-data` (там есть файлы и каталоги с пробелами в именах).

## Задача
Напиши `/usr/local/bin/backup-app.sh`:

```
backup-app.sh [SRC] [DST]
```
1. `SRC` по умолчанию `/srv/app-data`, `DST` по умолчанию `/var/backups/app-data`.
2. Создаёт архив `DST/<имя каталога SRC>-ГГГГММДД-ЧЧММСС.tar.gz` (например,
   `app-data-20261021-143005.tar.gz`). `DST` создаётся, если его нет.
3. Хранит только **5** последних архивов этого SRC; более старые удаляет. Количество можно
   переопределить переменной окружения `KEEP`.
4. Чужие файлы в `DST` (не архивы этого скрипта) не трогает.
5. Если `SRC` не существует — пишет ошибку в **stderr** и завершается с ненулевым кодом.
6. Об успехе пишет в системный журнал с тегом `backup-app` (`logger -t backup-app ...`).
7. Корректно работает с пробелами в путях `SRC` и `DST`.

## Критерии готовности (что проверяет check)
Check запускает скрипт 7 раз подряд и проверяет: осталось ровно 5 архивов, архив
валиден и содержит файлы с пробелами в именах, чужой файл в `DST` на месте, кастомные
пути с пробелами работают, без `SRC` — ненулевой код и сообщение в stderr, в журнале
есть записи `backup-app`.
