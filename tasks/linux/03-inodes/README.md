# linux-03 · No space left on device при свободном месте

**Уровень:** Middle · **Тема:** Linux / ФС · **Время:** ~15 мин

## Легенда
Сервис `sessions` хранит сессии пользователей файлами в `/var/lib/sessions/store`
(отдельный диск). Сервис начал отвечать 500, в логах `No space left on device`. Коллега
посмотрел `df -h`, увидел, что свободно больше половины диска, и сказал, что дело не в диске.

## Симптомы
- `curl http://127.0.0.1:8003/health` → 500
- `df -h /var/lib/sessions` — место есть

## Задача
Разберись, чего на самом деле не хватает, и почини сервис.

## Ограничения
- Сессии, изменённые за последние сутки, — активные, удалять их нельзя.
- Сессии старше суток можно удалять.
- Диск не переформатировать.

## Критерии готовности (что проверяет check)
- на `/var/lib/sessions` занято меньше 50% inode
- все активные (свежие) сессии на месте
- `/health` → 200, `POST /write` → 201
