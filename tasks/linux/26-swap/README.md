# linux-26 · Добавить swap и настроить swappiness

**Уровень:** Junior · **Тема:** Linux / память · **Время:** ~10 мин

## Легенда
На небольшом сервере периодически кончается память, и OOM killer убивает процессы.
Пока команда оптимизирует приложение, решили добавить немного swap как страховку,
но сделать так, чтобы ядро прибегало к нему как можно реже.

## Задача
1. Создай swap-файл `/var/lib/swap/trainer.swap` размером 512 MiB и включи его.
2. Он должен подключаться автоматически после перезагрузки.
3. Выстави `vm.swappiness=10` сейчас и так, чтобы значение сохранилось после ребута.

## Ограничения
- Существующий swap (если он есть) не трогать.
- Файл swap не должен быть доступен на чтение никому, кроме root.

## Критерии готовности (что проверяет check)
- `/var/lib/swap/trainer.swap` активен (`swapon --show`), размер не меньше 500 MiB, права 600
- в `/etc/fstab` есть запись для него
- `vm.swappiness` = 10 сейчас и задан в `/etc/sysctl.conf` или `/etc/sysctl.d/*.conf`
