# linux-23 · Фаервол режет порт сервиса

**Уровень:** Junior/Middle · **Тема:** Linux / сеть, iptables · **Время:** ~15 мин

## Легенда
Безопасники раскатили на сервер «харднинг» фаервола. После этого перестал открываться
дашборд `dashboard` на порту 8023: запросы просто висят. Сервис при этом запущен и
слушает порт. Если что-то поправить вручную, после перезагрузки снова ломается.

## Задача
Открой доступ к порту 8023 так, чтобы это пережило перезагрузку.

## Ограничения
- Фаервол целиком не выключать: остальные правила харднинга (например, закрытый
  debug-порт 8099) должны остаться.
- SSH не трогать.

## Критерии готовности (что проверяет check)
- `curl http://127.0.0.1:8023/health` → 200 за пару секунд
- правило, закрывающее 8099, на месте
- после `systemctl restart fw-hardening` (так правила применяются при загрузке) порт 8023 по-прежнему доступен
