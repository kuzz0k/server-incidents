# linux-13 · Сервис в бесконечном рестарте

**Уровень:** Junior · **Тема:** Linux / systemd, логи · **Время:** ~10 мин

## Легенда
После выкатки нового конфига сервис каталога `catalog` сначала перезапускался каждую
секунду, а теперь висит в `failed` и на `systemctl restart` не реагирует.
Конфиг: `/etc/catalog/catalog.conf`. По требованиям сервису нужны `DB_HOST=10.0.0.5`
и `CACHE_TTL=300`.

## Задача
Найди причину по логам, исправь конфиг и верни сервис в строй.

## Ограничения
- Юнит `catalog.service` не менять (политика рестартов задана специально).

## Критерии готовности (что проверяет check)
- `catalog` активен и не перезапускается 5 секунд подряд
- `curl http://127.0.0.1:8013/health` → 200
- в конфиге `DB_HOST=10.0.0.5` и `CACHE_TTL=300`
