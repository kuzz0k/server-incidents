# linux-28 · apt не может установить пакеты

**Уровень:** Junior · **Тема:** Linux / пакеты · **Время:** ~15 мин

## Легенда
Разработчик попросил поставить на сервер `jq` и `tree`. `apt` отказывается работать,
причём ошибки разные в зависимости от того, что пытаешься сделать. Недавно на сервер
добавляли репозиторий вендора и ставили какой-то «агент автообновлений».

## Задача
Почини apt и установи пакеты `jq` и `tree`.

## Ограничения
- Не удалять файлы блокировок (`/var/lib/dpkg/lock*`) руками: найди, кто их держит.
- Системные списки репозиториев Ubuntu не трогать.

## Критерии готовности (что проверяет check)
- `apt-get update` проходит без ошибок (`E:`)
- `jq` и `tree` установлены
- никакой процесс не держит блокировку dpkg, «агент автообновлений» остановлен и не запустится при загрузке
