# linux-15 · Address already in use

**Уровень:** Junior · **Тема:** Linux / сеть, systemd · **Время:** ~10 мин

## Легенда
Новый API-шлюз `gateway` должен слушать порт 8015, но не запускается. Говорят, когда-то
на этом сервере крутился старый шлюз, который «давно выключили».

## Задача
Найди, кто занимает порт, освободи его для `gateway` и сделай так, чтобы после ребута
ситуация не повторилась.

## Ограничения
- Порт `gateway` менять нельзя: на 8015 настроены балансировщики.

## Критерии готовности (что проверяет check)
- `gateway` активен, на 8015 слушает именно он (`curl http://127.0.0.1:8015/` → `gateway ok`)
- старый шлюз остановлен и не запустится при загрузке
