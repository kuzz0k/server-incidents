# linux-07 · Сервис не может прочитать конфиг

**Уровень:** Junior · **Тема:** Linux / права · **Время:** ~10 мин

## Легенда
Сервис складского учёта `inventory` перенесли на новый сервер: скопировали конфиг
`/etc/inventory/config.ini` и создали каталог данных `/var/lib/inventory`. Сервис
работает от пользователя `inventory` и не запускается.

## Задача
Запусти сервис и добейся, чтобы `curl http://127.0.0.1:8007/health` отвечал 200.

## Ограничения
- В конфиге пароль от БД: он не должен быть доступен на чтение всем пользователям.
- Никаких `chmod 777`: каталог данных не должен быть доступен на запись всем.
- Сервис должен работать от `inventory`, а не от root.

## Критерии готовности (что проверяет check)
- `inventory` активен и работает от пользователя `inventory`
- `/health` → 200 (сервис может писать в каталог данных)
- конфиг не читается «прочими» (other), каталог данных не world-writable
