# linux-09 · Не пускает по SSH-ключу

**Уровень:** Junior · **Тема:** Linux / SSH, права · **Время:** ~10 мин

## Легенда
Новой разработчице Алисе завели пользователя `alice` и положили её публичный ключ
в `authorized_keys`. Она не может зайти: SSH просит пароль, а пароля у неё нет.
Приватный ключ Алисы для проверки лежит в `/root/trainer-keys/alice_ed25519`.

Проверка входа:
```bash
ssh -i /root/trainer-keys/alice_ed25519 -o StrictHostKeyChecking=no alice@127.0.0.1 id
```
(если sshd слушает другой порт — добавь `-p <порт>`)

## Задача
Сделай так, чтобы Алиса заходила по ключу и получала нормальный shell.

## Ограничения
- `sshd_config` не менять (в том числе не выключать `StrictModes`).
- Ключ не перегенерировать.

## Критерии готовности (что проверяет check)
- `ssh -i alice_ed25519 alice@127.0.0.1 id -un` выводит `alice`
- домашний каталог alice не доступен на запись группе и прочим
