# linux-02 · df показывает 100%, а du — почти пусто

**Уровень:** Middle · **Тема:** Linux / диски, процессы · **Время:** ~15 мин

## Легенда
Диск `/var/lib/metrics` заполнился. Дежурный «почистил» его: удалил огромный
`agent.log`. Но место так и не освободилось, а файла `agent.log` в каталоге больше нет.
Агент сбора метрик `metrics-agent` при этом работает.

## Симптомы
- `df -h /var/lib/metrics` → почти 100%
- `du -sh /var/lib/metrics` → несколько килобайт

## Задача
Объясни, куда делось место, освободи его и сделай так, чтобы агент снова писал
лог в `/var/lib/metrics/agent.log`.

## Ограничения
- Агент должен продолжать работать (остановить и забыть нельзя).
- Диск не отмонтировать и не пересоздавать.

## Критерии готовности (что проверяет check)
- на `/var/lib/metrics` занято меньше 50%
- ни один процесс не держит открытыми удалённые файлы на этом диске
- `metrics-agent` активен и дописывает в существующий `/var/lib/metrics/agent.log`
