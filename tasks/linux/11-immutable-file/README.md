# linux-11 · root не может изменить файл

**Уровень:** Junior · **Тема:** Linux / атрибуты ФС · **Время:** ~10 мин

## Легенда
Нужно поднять таймаут платёжного шлюза. Это делает скрипт `/opt/payment/deploy.sh`:
он меняет `/etc/payment/config.yml` и пишет запись в журнал аудита
`/var/log/payment/audit.log`. Скрипт падает с `Operation not permitted`, хотя запускается
от root, а права на файл `644 root:root`.

## Задача
Выполни деплой (`/opt/payment/deploy.sh` должен отработать, в конфиге должно оказаться
`timeout: 30`) и после этого верни конфигу защиту, которая на нём стояла.

## Ограничения
- Журнал аудита должен остаться append-only, как и был: из него нельзя удалять строки.
- Сам скрипт деплоя не менять.

## Критерии готовности (что проверяет check)
- в `/etc/payment/config.yml` стоит `timeout: 30`
- конфиг снова защищён от изменений тем же способом, что и до деплоя
- `audit.log` остался append-only и в нём есть запись о деплое
