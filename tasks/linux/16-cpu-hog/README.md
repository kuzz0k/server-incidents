# linux-16 · Сервер тормозит: кто-то ест CPU

**Уровень:** Middle · **Тема:** Linux / процессы, производительность · **Время:** ~15 мин

## Легенда
Мониторинг показывает, что одно ядро сервера загружено на 100% с тех пор, как вчера
выкатили новую версию конфигов. Очередь задач при этом пустая, сервер ничего полезного не делает.

## Задача
Найди процесс и сервис, который ест CPU, выясни причину и устрани её так, чтобы
сервис продолжал работать.

## Ограничения
- Сервис должен остаться запущенным: он нужен, просто работает неправильно.
- Не ограничивать сервис квотами (`CPUQuota=`, `nice`, cgroups): нужно найти и устранить причину.

## Критерии готовности (что проверяет check)
- виновный сервис активен
- он потребляет меньше 20% одного ядра
- у него нет `CPUQuota`
