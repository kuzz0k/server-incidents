# linux-31 · Починить сломанный deploy.sh

**Уровень:** Junior/Middle · **Тема:** Linux / bash · **Время:** ~20 мин

## Легенда
Скрипт деплоя `/opt/deploy/deploy.sh` прислали из Windows-ноутбука. Он должен
распаковать артефакт `/opt/deploy/artifacts/app-<версия>.tar.gz` в каталог
`/opt/deploy/release store/<версия>` (да, с пробелом — так исторически сложилось)
и переключить симлинк `/opt/deploy/current` на новый релиз. Сейчас скрипт не запускается
вообще, а когда запустится — сломается дальше.

## Задача
Почини скрипт так, чтобы:
1. `/opt/deploy/deploy.sh 1.2.3` из **любого** текущего каталога разворачивал релиз 1.2.3,
   переключал `current` и завершался с кодом 0;
2. `deploy.sh` без аргументов печатал usage и завершался с кодом 1;
3. `deploy.sh 9.9.9` (артефакта нет) завершался с ненулевым кодом и **не трогал** `current`;
4. скрипт не создавал мусор в текущем каталоге.

## Критерии готовности (что проверяет check)
Ровно эти четыре сценария, плюс в файле нет CRLF.
