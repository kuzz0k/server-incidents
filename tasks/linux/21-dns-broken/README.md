# linux-21 · Не работает DNS

**Уровень:** Junior/Middle · **Тема:** Linux / сеть, DNS · **Время:** ~15 мин

## Легенда
После того как коллега «настроил корпоративный DNS», сервер перестал ходить в интернет
по именам: `apt update` падает, `curl https://archive.ubuntu.com` не работает. При этом
`ping 1.1.1.1` проходит.

## Задача
Верни нормальное разрешение имён. Корпоративный DNS-сервер 192.0.2.53 больше не
существует, использовать его не нужно.

## Ограничения
- Сервер использует systemd-resolved — так и должно остаться.
- Публичные DNS (8.8.8.8 и т.п.) жёстко не прописывать: DNS должен приходить из настроек сети (DHCP/netplan).

## Критерии готовности (что проверяет check)
- `getent hosts archive.ubuntu.com` возвращает адрес
- `/etc/resolv.conf` — симлинк на конфиг systemd-resolved, адреса 192.0.2.53 нет ни в нём, ни в `resolvectl status`
