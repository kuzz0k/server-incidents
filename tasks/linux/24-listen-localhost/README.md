# linux-24 · Сервис недоступен с других машин

**Уровень:** Junior · **Тема:** Linux / сеть · **Время:** ~10 мин

## Легенда
Prometheus с соседнего сервера не может забрать метрики у `metrics-api` (порт 8024):
`connection refused`. Админ заходит на сервер, делает `curl localhost:8024/health` —
всё работает. Фаервол на сервере не настроен.

## Задача
Сделай так, чтобы `metrics-api` был доступен по сетевому адресу сервера, а не только локально.
Конфиг сервиса — `/etc/metrics-api.conf`.

Проверить «как с другой машины» можно с самого сервера по его IP:
```bash
curl http://$(hostname -I | awk '{print $1}'):8024/health
```

## Критерии готовности (что проверяет check)
- `metrics-api` активен
- `curl http://<основной IP сервера>:8024/health` → 200
