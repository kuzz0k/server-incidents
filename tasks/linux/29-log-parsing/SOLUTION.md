# linux-29 · Разбор

Формат combined: `$1` — IP, `$4` — `[дата:час:мин:сек`, `$7` — URL, `$9` — код ответа.

```bash
LOG=/var/log/trainer/access.log
head -3 $LOG                                         # сначала смотрим формат!

# топ-3 IP
awk '{print $1}' $LOG | sort | uniq -c | sort -rn | head -3

# количество 5xx
awk '$9 ~ /^5/' $LOG | wc -l
awk '$9 >= 500 && $9 < 600 {n++} END {print n}' $LOG

# URL с наибольшим числом 404
awk '$9 == 404 {print $7}' $LOG | sort | uniq -c | sort -rn | head -1

# уникальные IP за 14-й час
awk '{split($4, t, ":"); if (t[2] == "14") print $1}' $LOG | sort -u | wc -l
grep -F ':14:' $LOG | ...         # осторожно: ':14:' может совпасть с минутами!
```

Ответ:
```bash
cat > /root/answers/linux-29.txt <<EOF
top_ip1=...
...
EOF
```

## Подводные камни
- `uniq` работает только с **отсортированным** входом.
- `grep ':14:'` найдёт и `12:14:05` (минуты) — нужно разбирать поле по позиции.
- В User-Agent и URL бывают пробелы: для сложного разбора лучше парсить по кавычкам (`awk -F'"'`).
