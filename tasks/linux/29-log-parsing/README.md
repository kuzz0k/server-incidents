# linux-29 · Разбор access.log в консоли

**Уровень:** Junior · **Тема:** Linux / bash, обработка текста · **Время:** ~20 мин

## Легенда
Вчера в 14:00 сайт тормозил. Есть лог nginx за сутки в формате combined:
`/var/log/trainer/access.log` (~50 тысяч строк). Нужно быстро ответить на вопросы,
не загружая лог никуда, только средствами консоли (`awk`, `sort`, `uniq`, `grep`, `cut`…).

## Задача
Запиши ответы в `/root/answers/linux-29.txt` в формате `key=value`:

```
top_ip1=<IP с наибольшим числом запросов>
top_ip2=<второй по числу запросов>
top_ip3=<третий>
errors_5xx=<сколько всего ответов с кодом 5xx>
top_404_url=<URL, который чаще всего отдавал 404>
unique_ips_14h=<сколько уникальных IP делали запросы с 14:00:00 до 14:59:59>
```

## Критерии готовности (что проверяет check)
Все шесть ответов совпадают с тем, что на самом деле в логе.
