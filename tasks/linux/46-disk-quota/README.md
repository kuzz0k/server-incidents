# linux-46 · Disk quota exceeded при свободном месте

**Уровень:** Junior/Middle · **Тема:** Linux / диски, квоты · **Время:** ~15 мин

## Легенда
CI-раннер `ci-runner` (порт 8046) работает от пользователя `builder` и складывает сборки в `/srv/ci`.
Сборки падают с `Disk quota exceeded`, хотя `df -h /srv/ci` показывает, что диск почти пустой.
По регламенту пользователю `builder` положено **200 МБ** на этом диске, а сейчас ему выдано меньше.

## Задача
Почини сборки, приведя лимит `builder` в соответствие с регламентом.

## Ограничения
- Квоты на диске не отключать: они защищают диск от одного «прожорливого» пользователя.
- Старые артефакты (`/srv/ci/artifacts`) не удалять: их забирают тестировщики.

## Критерии готовности (что проверяет check)
- квоты на `/srv/ci` включены, жёсткий лимит `builder` по блокам — не меньше 200 МБ
- артефакты на месте, `ci-runner` активен, `/health` → 200
