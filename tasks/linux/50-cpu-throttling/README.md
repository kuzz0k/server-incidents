# linux-50 · Сервис тормозит, а сервер простаивает

**Уровень:** Middle · **Тема:** Linux / cgroups, производительность · **Время:** ~15 мин

## Легенда
Расчёт цены в `pricing-api` (`GET http://127.0.0.1:8050/price`) выполняется 5 секунд вместо
привычных 0,2. При этом `top` показывает, что процессор сервера почти свободен, а сам сервис
ест всего несколько процентов CPU. Недавно для сервисов «навели порядок с лимитами».

## Задача
Найди, что тормозит расчёт, и добейся ответа `/price` быстрее чем за 1,5 секунды.

## Ограничения
- Лимит CPU у сервиса нужен (защита соседей): не снимай его полностью, но и не ставь больше 100% (одного ядра).
- Исходный юнит не редактировать: только drop-in.

## Критерии готовности (что проверяет check)
- `GET /price` отвечает 200 быстрее 1,5 с
- у сервиса есть лимит `CPUQuota` в диапазоне 30–100%, задан через drop-in
