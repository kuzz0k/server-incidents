# linux-53 · Отчёты есть, но веб их не видит

**Уровень:** Junior/Middle · **Тема:** Linux / права, systemd · **Время:** ~15 мин

## Легенда
Сервис `report-exporter` (пользователь `exporter`) каждые пару секунд кладёт свежий отчёт в
`/srv/reports`. Веб-сервис `reports-web` (пользователь `www-reports`, входит в группу `reports`)
отдаёт последний отчёт на `http://127.0.0.1:8053/latest`. Каталог `/srv/reports` принадлежит группе
`reports`, у него setgid. Но `/latest` отвечает 500.

## Задача
Сделай так, чтобы веб-сервис читал отчёты: и уже созданные, и будущие.

## Ограничения
- Отчёты не должны быть доступны на чтение «всем» (other): там персональные данные.
- Сервисы не запускать от root и не менять их пользователей.
- Исходные юниты не редактировать: только drop-in.

## Критерии готовности (что проверяет check)
- `GET /latest` → 200 (последний отчёт)
- все отчёты в `/srv/reports` читаются группой и не читаются прочими
- у `report-exporter` задан `UMask`, при котором новые файлы читаются группой и закрыты для прочих
