# linux-59 · Кто съедает память сервера

**Уровень:** Middle · **Тема:** Linux / память, cgroups · **Время:** ~15 мин

## Легенда
Мониторинг показывает, что свободная память на сервере тает: за пару минут минус несколько сотен
мегабайт. На сервере крутится несколько сервисов. Разработчики обещают найти утечку к следующему релизу,
а пока нужно, чтобы виновник не уронил сервер.

## Задача
1. Найди сервис, который течёт, и запиши его юнит в `/root/answers/linux-59.txt`:
   ```
   unit=<имя юнита, например foo.service>
   ```
2. Ограничь его так, чтобы он не мог занять больше **300 МБ** и автоматически перезапускался,
   когда упирается в лимит. Настройка должна пережить перезагрузку.

## Ограничения
- Сервис не останавливать насовсем: он нужен, пусть и с утечкой.
- Остальные сервисы не трогать.

## Критерии готовности (что проверяет check)
- в ответе правильный юнит
- у юнита `MemoryMax` ≤ 300M (не infinity), политика `Restart` — `on-failure` или `always`
- сейчас сервис занимает не больше 300 МБ, юнит не выключен
