# linux-43 · Скрипт очистки логов делает не то

**Уровень:** Junior · **Тема:** Linux / bash, find · **Время:** ~20 мин

## Легенда
Каждую ночь `/usr/local/bin/clean-logs.sh` должен наводить порядок в `/var/log/app-cleaner`:
- `*.log` старше 1 суток сжимать в `.gz` (`gzip`);
- `*.gz` старше 7 суток удалять;
- сегодняшние логи и остальные файлы не трогать.

На деле он удаляет свежие архивы, не трогает старые и ломается на файлах с пробелами в имени.
Каталог с примерами файлов уже подготовлен: `ls -l --time-style=+%F /var/log/app-cleaner`.

## Задача
Почини `clean-logs.sh`, чтобы он делал ровно то, что описано.

## Критерии готовности (что проверяет check)
Check каждый раз создаёт набор файлов с разным возрастом (в том числе с пробелами в именах),
запускает скрипт и сверяет результат: что сжато, что удалено, что не тронуто.
Скрипт должен работать из любого текущего каталога.

> Не читай `check.sh` — там ожидаемый результат.
