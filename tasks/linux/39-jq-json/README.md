# linux-39 · JSON в CSV: разбор инвентаря через jq

**Уровень:** Junior · **Тема:** Linux / обработка данных · **Время:** ~20 мин

## Легенда
Система инвентаризации выгрузила список серверов в `/srv/inventory/servers.json` (массив объектов:
`name`, `dc`, `ip`, `cpu_load`, `status`, `tags`). Нужно быстро ответить на вопросы и
отдать коллегам CSV. Задача популярна на live-coding: обычно разрешают `jq` (поставь его, если нет) или Python.

## Задача
1. Запиши ответы в `/root/answers/linux-39.txt`:
   ```
   down_count=<сколько серверов со статусом down>
   hot_msk1=<имена серверов в dc msk-1 с cpu_load > 80, по алфавиту, через запятую>
   top_dc=<dc, в котором больше всего серверов со статусом up>
   db_tagged=<сколько серверов с тегом db>
   ```
2. Сделай CSV `/root/answers/linux-39.csv`: заголовок `name,dc,ip,status`, затем все серверы,
   отсортированные по `name`. Без кавычек вокруг значений.

## Критерии готовности (что проверяет check)
Все ответы и CSV совпадают с тем, что на самом деле в JSON.
