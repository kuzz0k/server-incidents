# linux-12 · Сервис не стартует

**Уровень:** Junior · **Тема:** Linux / systemd · **Время:** ~10 мин

## Легенда
Разработчик написал systemd-юнит для API заказов `orders` и ушёл в отпуск. Сервис не
запускается, ни на 8012 порту, ни после перезагрузки. Настройки сервиса лежат в
`/etc/default/orders`.

## Задача
Запусти сервис и сделай так, чтобы он поднимался при загрузке.

## Ограничения
- Сервис запускается через systemd, а не руками в фоне (`nohup`, `&`, `screen`).
- Настройки остаются в `/etc/default/orders`.

## Критерии готовности (что проверяет check)
- `orders.service` активен и включён в автозагрузку
- `curl http://127.0.0.1:8012/health` → 200
