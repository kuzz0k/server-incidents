# linux-17 · Зомби-процессы

**Уровень:** Junior/Middle · **Тема:** Linux / процессы · **Время:** ~10 мин

## Легенда
Мониторинг ругается: на сервере полсотни процессов в состоянии `Z`. Дежурный пытался
сделать им `kill -9`, но они никуда не делись.

## Задача
1. Найди процесс-родитель зомби и запиши его PID в `/root/answers/linux-17.txt`:
   ```
   parent_pid=<PID>
   ```
2. Избавься от зомби. Родительский процесс — устаревший пакетный обработчик, он больше не нужен.

## Критерии готовности (что проверяет check)
- в ответе указан правильный PID родителя
- родительского процесса больше нет
- зомби этого обработчика в системе не осталось
