# linux-57 · Программа не находит конфиг, а какой — не говорит

**Уровень:** Junior/Middle · **Тема:** Linux / strace, отладка · **Время:** ~15 мин

## Легенда
Вендорский сервис геокодинга `geo-api` (порт 8057) после обновления не стартует. В логе одна строка:
`configuration error, exiting`. Конфиг по инструкции вендора лежит в `/etc/geo-api.conf` и в нём
всё правильно. Исходников нет.

## Задача
Выясни, **где** сервис ищет конфиг, и запусти его с этим конфигом.

## Ограничения
- Содержимое конфига не менять.
- Сервис не переписывать и не подменять.

## Критерии готовности (что проверяет check)
- `geo-api` активен и стабилен 5 секунд, `/health` → 200
- конфиг лежит там, где его ищет программа
