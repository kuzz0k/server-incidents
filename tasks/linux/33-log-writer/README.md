# linux-33 · Кто пишет в этот лог?

**Уровень:** Junior · **Тема:** Linux / процессы, файлы · **Время:** ~10 мин

## Легенда
Файл `/var/log/trainer/bad.log` растёт на глазах: по несколько строк в секунду.
Никто не помнит, какая программа туда пишет. Аудиторы просят сохранить лог как есть.

## Задача
Найди процесс, который пишет в `bad.log`, и останови запись насовсем, чтобы она не
возобновилась и после перезагрузки. Этот процесс больше не нужен.

## Ограничения
- `bad.log` не удалять и не очищать.

## Критерии готовности (что проверяет check)
- `bad.log` на месте и не стал меньше
- файл не растёт 5 секунд, его не держит открытым ни один процесс
- виновный сервис остановлен и не запустится при загрузке
