# linux-44 · Клиент не достучался до API: куда он ходит?

**Уровень:** Middle · **Тема:** Linux / сеть, tcpdump · **Время:** ~20 мин

## Легенда
Сервис `order-sync` раз в секунду отправляет заказы в API `orders-api` (оно работает на этом же
сервере, порт **8044**). После переезда в логе `order-sync` только
`ERROR upstream request failed`, без адреса и подробностей. Разработчик утверждает, что
«конфиг правильный».

## Задача
1. Выясни сетевыми средствами, **на какой адрес и порт** на самом деле подключается `order-sync`,
   и запиши в `/root/answers/linux-44.txt`:
   ```
   dest=<ip>:<port>
   ```
2. Почини настройку клиента, чтобы запросы доходили до `orders-api`.

## Ограничения
- `orders-api` не трогать и не переносить на другой порт.

## Критерии готовности (что проверяет check)
- в ответе правильные адрес и порт, куда ходил клиент
- `order-sync` активен, в его логе появляется `sync ok`
- `orders-api` получает запросы от клиента
