# linux-61 · REMOTE HOST IDENTIFICATION HAS CHANGED

**Уровень:** Middle · **Тема:** Linux / SSH · **Время:** ~15 мин

## Легенда
Сервис `mirror-sync` (пользователь `syncer`) каждые несколько секунд ходит по SSH на зеркало
`gitmirror@127.0.0.1:2222` (в учебных целях зеркало — отдельный sshd на этом же сервере). Вчера
сервер зеркала переустановили, и синхронизация встала. Админ зеркала прислал отпечаток нового
ключа хоста: он лежит в `/root/trainer-notes/linux-61.txt`.

## Задача
Восстанови синхронизацию **безопасно**: убедись, что новый ключ хоста действительно тот, который
прислал админ, и обнови доверие к нему.

## Ограничения
- Не отключать проверку ключа хоста (`StrictHostKeyChecking=no`, `UserKnownHostsFile=/dev/null` и т.п.).
- Учебный sshd на 2222 и ключи на стороне зеркала не трогать.

## Критерии готовности (что проверяет check)
- в логе `mirror-sync` снова появляется `sync ok`
- в `known_hosts` у `syncer` для `[127.0.0.1]:2222` записан новый ключ, а старого нет
- проверка ключа хоста не отключена ни в конфигах ssh, ни в сервисе
