# linux-27 · Сбито системное время

**Уровень:** Junior · **Тема:** Linux / время, NTP · **Время:** ~10 мин

## Легенда
С сервером творится странное: `apt update` пишет `Release file ... is not valid yet`,
время в логах не совпадает с реальным, а разработчики жалуются, что в логах приложений
«чужой» часовой пояс.

## Задача
Синхронизируй время и настрой часовой пояс по стандарту компании.

## Ограничения
- Стандарт компании: все серверы в **UTC**.
- Время должно синхронизироваться автоматически (NTP), а не выставляться руками.

## Критерии готовности (что проверяет check)
- часовой пояс `UTC` (`Etc/UTC`)
- NTP-синхронизация включена (`timedatectl`: `NTP service: active`)
- расхождение с реальным временем меньше 60 секунд (сверяется с заголовком `Date` от archive.ubuntu.com)
