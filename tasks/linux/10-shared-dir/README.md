# linux-10 · Общая папка для команды

**Уровень:** Junior/Middle · **Тема:** Linux / права, ACL · **Время:** ~15 мин

## Легенда
Команде разработки (группа `devteam`: пользователи `dev1`, `dev2`) нужен общий каталог
`/srv/projects`. Пользователь `dev3` из другой команды доступа иметь не должен.
Сейчас каталог принадлежит root и туда никто, кроме root, писать не может.

## Задача
Настрой `/srv/projects` так, чтобы:
1. `dev1` и `dev2` могли создавать там файлы и каталоги проектов;
2. всё новое (в том числе во вложенных каталогах) автоматически принадлежало группе `devteam`;
3. внутри каталогов проектов (`/srv/projects/<проект>/`) участники могли **редактировать** файлы
   друг друга, даже если у пользователя `umask 022`;
4. в корне `/srv/projects` участник **не мог удалить** чужой файл или каталог;
5. остальные пользователи (`dev3`) не могли даже посмотреть содержимое.

## Ограничения
- Никаких `chmod 777` / `o+rwx`.
- umask пользователей не трогать.

## Критерии готовности (что проверяет check)
Check от имени пользователей создаёт, дописывает и удаляет файлы и проверяет все пять пунктов.
