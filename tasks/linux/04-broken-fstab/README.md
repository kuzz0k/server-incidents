# linux-04 · Диски не монтируются после замены

**Уровень:** Middle · **Тема:** Linux / fstab · **Время:** ~15 мин

## Легенда
На сервере два диска с данными: `/data` и `/backup`. Вчера диск под `/data` заменили
на новый и перенесли на него данные. Сегодня после перезагрузки ни `/data`, ни
`/backup` не смонтированы, а `mount -a` ругается.

## Симптомы
- `findmnt /data`, `findmnt /backup` — пусто
- `mount -a` завершается с ошибкой

## Задача
Почини `/etc/fstab`, чтобы оба диска монтировались автоматически и переживали ребут.
Нужный диск узнаешь по файлу `.disk-id` в корне ФС (`disk=data`, `disk=backup`).

## Ограничения
- Диски не переформатировать: на них данные.
- В fstab указывать диски по UUID или LABEL, а не по `/dev/loopN` (имена устройств могут поменяться).
- Сервер должен загружаться, даже если какого-то из дисков нет (опция `nofail` должна остаться).
- Перезагружаться не обязательно, но если перезагрузишься — VM загрузится (nofail).

## Критерии готовности (что проверяет check)
- для `/data` и `/backup` в fstab ровно по одной записи, по UUID или LABEL, с `nofail`
- `mount /data` и `mount /backup` монтируют правильные диски (проверяется `.disk-id`)
