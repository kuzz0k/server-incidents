# linux-34 · Высокий load average при простаивающем CPU

**Уровень:** Middle · **Тема:** Linux / производительность, I/O · **Время:** ~20 мин

## Легенда
Пользователи жалуются, что сервер «подтормаживает». `uptime` показывает заметный load average,
а `top` — что процессор почти ничего не делает. Классический вопрос с собеседования.

## Задача
1. Найди, что создаёт нагрузку, и запиши systemd-юнит виновника в `/root/answers/linux-34.txt`:
   ```
   unit=<имя юнита, например foo.service>
   ```
2. Виновник — плановая переиндексация, она нужна. Не останавливай её, а сделай так, чтобы она
   **уступала диск и CPU** всем остальным: класс ввода-вывода `idle` и nice не меньше 10.
   Настройка должна пережить перезапуск сервиса.

## Критерии готовности (что проверяет check)
- в ответе правильный юнит
- юнит активен, у него `IOSchedulingClass=idle` и `Nice` ≥ 10 (в настройках юнита)
- у работающего процесса действительно класс I/O `idle`
