# linux-40 · Скрипт-алерт о заполнении дисков

**Уровень:** Junior · **Тема:** Linux / bash · **Время:** ~25 мин

## Легенда
Частое тестовое: «напиши скрипт, который проверяет заполнение дисков и шлёт алерт, если больше 85%».
Почтового сервера на стенде нет, поэтому «алерт» — запись в системный журнал.

## Задача
Напиши `/usr/local/bin/disk-alert.sh`:
```
disk-alert.sh [THRESHOLD]        # порог в процентах, по умолчанию 85
```
1. Проверяет все **реальные** файловые системы. tmpfs, devtmpfs, overlay и squashfs игнорирует.
2. Для каждой ФС с заполнением **≥ THRESHOLD** пишет строку в stderr и в журнал с тегом
   `disk-alert` (`logger -t disk-alert ...`). В сообщении должны быть точка монтирования и процент.
3. Код возврата: `1`, если был хотя бы один алерт, иначе `0`.
4. Скрипт запускается автоматически **каждые 5 минут** (cron или systemd timer — на выбор).

## Критерии готовности (что проверяет check)
Check монтирует тестовый диск, заполненный на ~90%, и tmpfs, заполненный на 100%, затем запускает скрипт:
- с порогом 85: код 1, в журнале `disk-alert` есть алерт про тестовый диск, а про tmpfs нет;
- с порогом 95: про тестовый диск алерта нет;
- без аргумента используется порог 85;
- есть расписание запуска (cron.d / crontab / systemd timer).
