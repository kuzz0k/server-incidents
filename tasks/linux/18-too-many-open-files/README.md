# linux-18 · Too many open files

**Уровень:** Middle · **Тема:** Linux / лимиты, systemd · **Время:** ~15 мин

## Легенда
Чат-сервер `chat-server` при старте открывает пул из 300 соединений и падает.
Предыдущий админ уже «поднял лимиты» в `/etc/security/limits.d/`, но не помогло.

## Задача
Сделай так, чтобы `chat-server` стабильно запускался.

## Ограничения
- Количество соединений в пуле (300) не уменьшать.
- Лимит должен сохраниться после перезагрузки и обновления пакета: исходный юнит
  лучше не редактировать, а переопределить.

## Критерии готовности (что проверяет check)
- `chat-server` активен и стабилен 5 секунд, `curl http://127.0.0.1:8018/health` → 200
- у сервиса `LimitNOFILE` не меньше 4096
- лимит задан через drop-in (`/etc/systemd/system/chat-server.service.d/*.conf`)
