# linux-01 · Закончилось место на диске

**Уровень:** Junior · **Тема:** Linux / диски · **Время:** ~10 мин

## Легенда
Ночью пришёл алерт: сервис отчётов `reports` перестал сохранять отчёты. Пользователи
жалуются, что кнопка «Сохранить» отдаёт ошибку 500. Данные сервиса лежат на отдельном
диске, смонтированном в `/var/lib/reports`.

## Симптомы
- `curl -X POST -d test http://127.0.0.1:8001/write` → 500
- `curl http://127.0.0.1:8001/health` → 500

## Задача
Найди, что съело место, освободи его и верни сервис в рабочее состояние.

## Ограничения
- Файлы `/var/lib/reports/data/*.db` — продовые данные, удалять и менять их нельзя.
- Диск не отмонтировать и сервис никуда не переносить.

## Критерии готовности (что проверяет check)
- `/var/lib/reports` по-прежнему смонтирован с отдельного диска
- на нём занято меньше 70%
- `data/*.db` на месте и не изменены
- сервис `reports` активен, `/health` → 200, `POST /write` → 201
