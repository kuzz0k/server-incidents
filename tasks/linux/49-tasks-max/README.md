# linux-49 · can't start new thread

**Уровень:** Middle · **Тема:** Linux / systemd, лимиты · **Время:** ~15 мин

## Легенда
Обработчик задач `job-runner` (порт 8049) при старте поднимает пул из 40 рабочих потоков.
После переноса на новый сервер он падает с ошибкой про потоки. Памяти и CPU на сервере полно,
`ulimit -u` у пользователя большой.

## Задача
Сделай так, чтобы `job-runner` стабильно работал с пулом из 40 потоков.

## Ограничения
- Размер пула (`WORKERS=40`) не уменьшать.
- Исходный юнит не редактировать: только переопределение (drop-in).

## Критерии готовности (что проверяет check)
- `job-runner` активен и стабилен 5 секунд, `/health` → 200
- у сервиса не меньше 40 задач (`TasksCurrent`), лимит `TasksMax` ≥ 64 или не ограничен
- лимит задан через drop-in в `/etc/systemd/system/job-runner.service.d/`
