# linux-32 · Найти файлы по признакам (find)

**Уровень:** Junior · **Тема:** Linux / find, права · **Время:** ~15 мин

## Легенда
После инцидента нужно разобраться, что творится в каталоге магазина `/srv/shop`:
там тысячи файлов, и большая часть не менялась годами.

## Задача
Найди и запиши ответы в `/root/answers/linux-32.txt` (`key=value`, пути абсолютные):

```
big_file=<единственный файл больше 100 MiB>
recent_configs=<файлы *.conf, изменённые за последние 24 часа, через запятую, по алфавиту>
world_writable=<единственный обычный файл, доступный на запись всем>
orphan_file=<единственный файл, у владельца которого нет учётной записи в системе>
```
Потом убери у `world_writable` файла право записи для «прочих».

## Критерии готовности (что проверяет check)
- все четыре ответа верные
- в `/srv/shop` не осталось world-writable обычных файлов
