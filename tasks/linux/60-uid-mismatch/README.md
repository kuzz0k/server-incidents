# linux-60 · Данные перенесли со старого сервера — Permission denied

**Уровень:** Junior · **Тема:** Linux / владельцы файлов, UID · **Время:** ~10 мин

## Легенда
Медиасервис `media-api` (порт 8060, пользователь `media`) переезжает на новый сервер. Данные
`/srv/media-store` распаковали из архива старого сервера. Пользователь `media` есть и тут, и там,
но сервис отвечает 500: `Permission denied`. «Так ведь владелец media, как и был!»

## Задача
Почини доступ сервиса к его данным.

## Ограничения
- UID пользователя `media` не менять: он закреплён в LDAP и используется на NFS.
- Никаких `chmod 777` / записи для всех.

## Критерии готовности (что проверяет check)
- `media-api` активен, `/health` → 200 (запись в каталог данных работает)
- в `/srv/media-store` нет файлов с владельцем или группой без учётной записи
- UID `media` не изменился, ничего не доступно на запись всем
