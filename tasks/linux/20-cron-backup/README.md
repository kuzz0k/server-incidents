# linux-20 · Cron не запускает бэкап

**Уровень:** Junior/Middle · **Тема:** Linux / cron · **Время:** ~15 мин

## Легенда
Для тестового стенда настроили бэкап базы каждую минуту: скрипт `/opt/backup/db-backup.sh`
кладёт архив в `/var/backups/db/`, вывод пишется в `/var/log/db-backup-ГГГГ-ММ-ДД.log`.
Задание лежит в `/etc/cron.d/`. Прошла неделя, а `/var/backups/db/` пустой.
Если запустить скрипт руками, всё работает.

## Задача
Почини расписание, чтобы бэкап реально делался каждую минуту от root.

## Ограничения
- Задание должно остаться системным: в `/etc/cron.d/`, а не в `crontab -e`.
- Лог должен писаться в файл с датой в имени, как задумано.

## Критерии готовности (что проверяет check)
- в течение ~2 минут в `/var/backups/db/` появляется новый архив
- появляется лог `/var/log/db-backup-<сегодняшняя дата>.log`
- задание лежит в `/etc/cron.d/`
