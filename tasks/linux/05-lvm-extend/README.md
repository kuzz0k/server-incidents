# linux-05 · Расширить LVM-том без простоя

**Уровень:** Middle · **Тема:** Linux / LVM · **Время:** ~15 мин

## Легенда
Каталог приложения `/srv/app` лежит на LVM-томе и заполнен на 95%. Админ уже
подключил к серверу ещё один диск, но в LVM его не добавил. Остановить приложение нельзя.

## Задача
Увеличь том под `/srv/app` за счёт нового диска так, чтобы место выросло **без
размонтирования**.

## Ограничения
- Не размонтировать `/srv/app` и не пересоздавать ФС.
- Данные в `/srv/app` должны остаться целыми.
- Какой диск новый, определи сам (подсказка: он не входит ни в одну VG).

## Критерии готовности (что проверяет check)
- логический том под `/srv/app` не меньше 700 MiB
- файловая система в `/srv/app` тоже выросла (не меньше 650 MiB)
- `/srv/app` смонтирован, данные не изменились, занято меньше 60%
