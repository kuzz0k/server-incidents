# docker-02 · Контейнер работает, а порт недоступен

**Уровень:** Junior · **Тема:** Docker / сеть · **Время:** ~10 мин

## Легенда
Сервис каталога запущен в контейнере `catalog` (скрипт `/opt/trainer-docker/catalog/run.sh`)
и должен быть доступен на хосте по порту 8202. `docker ps` показывает, что контейнер `Up`,
но `curl http://127.0.0.1:8202/health` не работает.

## Задача
Сделай сервис доступным на 8202, поправив скрипт запуска.

## Ограничения
- Образ `trainer/catalog:1.0` не пересобирать.
- Без `--network host`: контейнер должен остаться в bridge-сети с пробросом порта.

## Критерии готовности (что проверяет check)
Check запускает `run.sh`, затем проверяет:
- `curl http://127.0.0.1:8202/health` → 200
- у контейнера не `host`-сеть
