# docker-04 · Docker съел весь диск

**Уровень:** Middle · **Тема:** Docker / эксплуатация · **Время:** ~20 мин

## Легенда
На build-сервере кончается место, `/var/lib/docker` растёт каждый день. Там копятся
старые образы после сборок, остановленные контейнеры после тестов, а контейнер
`chatty` (запускается через `/opt/trainer-docker/chatty/run.sh`) пишет очень много логов.

## Задача
1. Убери мусор: висящие (dangling) образы и остановленные контейнеры.
2. Ограничь размер логов контейнеров **по умолчанию для всего Docker** (не больше 50 МБ на контейнер)
   и сделай так, чтобы ограничение действовало на `chatty`.

## Ограничения
- Образ `trainer/keep:prod` — продовый, его не удалять (даже если он сейчас не используется).
- Работающие контейнеры не удалять (`chatty` можно пересоздать через `run.sh`).

## Критерии готовности (что проверяет check)
- нет dangling-образов и остановленных контейнеров `junk-*`
- образ `trainer/keep:prod` на месте
- в `/etc/docker/daemon.json` задан `log-opts.max-size`
- `chatty` работает, у него действует `max-size`, его лог меньше 60 МБ
