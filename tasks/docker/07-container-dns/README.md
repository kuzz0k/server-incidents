# docker-07 · Контейнеры не видят друг друга по имени

**Уровень:** Junior · **Тема:** Docker / сети · **Время:** ~15 мин

## Легенда
Два контейнера без compose: `api` (приложение на порту 8000 внутри контейнера) и `web` (nginx на 8207,
проксирует на `http://api:8000`). Оба запускает `/opt/trainer-docker/proxy/run.sh`. Контейнер `web`
постоянно перезапускается, `curl http://127.0.0.1:8207/` не работает.

## Задача
Почини `run.sh`, чтобы `web` нашёл `api` по имени и сайт открылся.

## Ограничения
- Без `--link` (устарел), без `--network host` и без IP-адресов контейнеров в конфиге nginx.
- Конфиг nginx (`nginx.conf` рядом) не менять: имя `api` правильное.

## Критерии готовности (что проверяет check)
Check запускает `run.sh`, затем:
- `curl http://127.0.0.1:8207/` → ответ от `api`
- `api` и `web` в одной пользовательской (не default `bridge`) сети, без `--link`
