# terraform-01 · Terraform: state заблокирован, а инфраструктура разъехалась с кодом

**Уровень:** Middle · **Тема:** Terraform · **Время:** ~20 мин

## Легенда
Проект `/opt/trainer-tf/site` управляет конфигами сервиса в `/srv/tf-site/` (провайдер `hashicorp/local`,
state — локальный `terraform.tfstate`). Тебе нужно выкатить изменения, но `terraform plan` падает:
`Error acquiring the state lock`. Коллега говорит, что вчера «что-то запускал и ушёл домой».
Ещё кто-то правил файлы в `/srv/tf-site/` руками.

## Задача
1. Разберись, кто держит блокировку, и сними её **безопасно**.
2. Верни `/srv/tf-site/` к состоянию, описанному в коде (окружение `prod`), так, чтобы `terraform plan`
   не показывал изменений.

## Ограничения
- `terraform.tfstate` не удалять и не редактировать руками.
- Код (`*.tf`) не менять: истина — в коде.

## Критерии готовности (что проверяет check)
- не запущено ни одного процесса terraform, зависший запуск не вернётся после ребута
- `terraform plan -detailed-exitcode` → 0 (изменений нет)
- файлы в `/srv/tf-site/` соответствуют коду, state тот же (lineage не изменился)
