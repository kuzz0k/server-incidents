# postgres-05 · PostgreSQL не поднялся после ребута

**Уровень:** Middle · **Тема:** PostgreSQL / эксплуатация · **Время:** ~20 мин

## Легенда
Кластер PostgreSQL `orders` (порт **5433**) хранит данные на отдельном диске, смонтированном в
`/srv/pgdata`. На прошлой неделе диск переподключали и восстанавливали данные из копии.
После сегодняшней перезагрузки кластер не стартует.

```bash
pg_lsclusters
```

## Задача
Подними кластер `orders` с **его данными** (таблица `orders` в базе `orders`) так, чтобы он
поднимался и после следующих перезагрузок.

## Ограничения
- Кластер не пересоздавать и не инициализировать заново: данные на диске нужны.
- Права на каталог данных не ослаблять (`chmod 777` и т.п. PostgreSQL всё равно не примет).

## Критерии готовности (что проверяет check)
- кластер `orders` online, `psql -p 5433 -d orders` видит 300 заказов
- `/srv/pgdata` смонтирован с правильного диска, в fstab запись по UUID с `nofail`
- каталог данных принадлежит `postgres` и имеет права 0700 (или 0750)
