# postgres-04 · Too many connections

**Уровень:** Middle · **Тема:** PostgreSQL / соединения · **Время:** ~20 мин

## Легенда
Основное приложение (роль `app`, пароль `App-Pass-2026`, база `reportsdb`) внезапно
перестало подключаться к базе. Недавно на сервер добавили воркер отчётов `report-worker`
(роль `report`).

Проверка:
```bash
PGPASSWORD=App-Pass-2026 psql -h 127.0.0.1 -U app -d reportsdb -c 'select 1'
```

## Задача
1. Верни приложению доступ к базе.
2. Ограничь воркер так, чтобы он больше не мог занять все соединения: не больше **5**
   одновременных соединений у роли `report`.

## Ограничения
- `max_connections` не поднимать (на сервере мало памяти).
- Воркер нужен: не останавливать и не удалять его, `report` должен иметь доступ к базе.

## Критерии готовности (что проверяет check)
- `app` подключается к `reportsdb`
- у роли `report` лимит соединений от 1 до 5, сейчас открыто не больше 5
- `max_connections` = 20, `report-worker` активен
