# postgres-01 · Приложение не может подключиться к БД

**Уровень:** Junior/Middle · **Тема:** PostgreSQL / доступ · **Время:** ~20 мин

## Легенда
Для магазина подняли PostgreSQL на этом сервере. Приложение будет работать с **другого**
сервера (сымитируем подключением по основному IP этого сервера) под пользователем
`shop` с паролем `Shop-Pass-2026` к базе `shopdb` и читать таблицу `shop.orders`.
Админ БД говорит, что «всё создал», но приложение не может подключиться.

Проверка:
```bash
PGPASSWORD=Shop-Pass-2026 psql -h $(hostname -I | awk '{print $1}') -U shop -d shopdb -c 'select count(*) from shop.orders'
```

## Задача
Добейся, чтобы запрос выше работал (и по `127.0.0.1` тоже).

## Ограничения
- Никакого `trust` в `pg_hba.conf` для сетевых подключений: только пароль (scram-sha-256).
- `shop` не должен быть суперпользователем или владельцем базы.
- Пароль `shop` не менять.

## Критерии готовности (что проверяет check)
- запрос от `shop` по основному IP и по 127.0.0.1 возвращает 100
- в `host`-строках `pg_hba.conf` нет `trust`, `shop` не суперпользователь
