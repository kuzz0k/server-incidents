# postgres-02 · Медленный запрос

**Уровень:** Middle · **Тема:** PostgreSQL / производительность · **Время:** ~20 мин

## Легенда
Пользователи жалуются, что дашборд аналитики (`analytics-dashboard`) открывается
медленно. Он регулярно ходит в базу `analytics`. Медленные запросы (дольше 100 мс)
PostgreSQL уже пишет в свой лог.

## Задача
Найди медленный запрос и ускорь его.

## Ограничения
- Код дашборда (и текст запроса) менять нельзя.
- Данные не удалять, `max_connections`/память не крутить — нужно исправить причину.

## Критерии готовности (что проверяет check)
- в плане запроса дашборда нет `Seq Scan` по `events`, используется индекс
- запрос выполняется быстрее 20 мс
- `analytics-dashboard` по-прежнему работает
