# postgres-03 · Восстановить удалённую таблицу из бэкапа

**Уровень:** Junior/Middle · **Тема:** PostgreSQL / бэкапы · **Время:** ~20 мин

## Легенда
В CRM (база `crm`) разработчик по ошибке выполнил `DROP TABLE deals` на проде.
Есть ночной бэкап в `/var/backups/postgres/`. После бэкапа в таблицу `customers` успели
добавить новых клиентов — их терять нельзя.

## Задача
Верни таблицу `deals` из бэкапа, не откатывая остальную базу.

## Ограничения
- Базу `crm` не пересоздавать и целиком из бэкапа не восстанавливать: новые клиенты должны остаться.
- Таблица должна вернуться полностью: с данными, первичным ключом и внешним ключом на `customers`.

## Критерии готовности (что проверяет check)
- в `deals` столько же строк и та же сумма `amount`, что в бэкапе
- в `customers` есть и старые, и новые клиенты
- у `deals` есть PRIMARY KEY и FOREIGN KEY
