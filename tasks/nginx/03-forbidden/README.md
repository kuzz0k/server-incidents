# nginx-03 · 403 Forbidden и пропавшие картинки

**Уровень:** Junior · **Тема:** nginx / статика, права · **Время:** ~15 мин

## Легенда
Блог переносили на новый сервер: сайт `http://127.0.0.1:8103/`, файлы блога в
`/srv/www/blog`, картинки отдельно в `/srv/media/images` (URL `/images/...`).
Главная страница отдаёт `403 Forbidden`, а картинки — `404`.

## Задача
Почини раздачу так, чтобы открывались главная и `/images/logo.png`.

## Ограничения
- Файл `index.htm` генерирует CMS: не переименовывать его.
- Без `chmod 777` и без запуска nginx от root.

## Критерии готовности (что проверяет check)
- `GET /` → 200, страница блога
- `GET /images/logo.png` → 200
- `index.htm` на месте, в `/srv/www` и `/srv/media` нет world-writable файлов и каталогов
- nginx работает от `www-data`
