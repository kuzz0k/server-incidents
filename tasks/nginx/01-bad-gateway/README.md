# nginx-01 · 502 Bad Gateway

**Уровень:** Junior · **Тема:** nginx / reverse proxy · **Время:** ~10 мин

## Легенда
Интернет-магазин работает за nginx: `http://127.0.0.1:8101/` → бэкенд `shop-backend`.
После вчерашнего обновления бэкенда сайт отдаёт `502 Bad Gateway`. Разработчики
говорят, что бэкенд запущен и здоров.

## Задача
Верни сайт в строй.

## Ограничения
- Порт бэкенда не менять: на него завязаны другие системы.
- Бэкенд не перезапускать с другими параметрами: чинить нужно nginx.

## Критерии готовности (что проверяет check)
- `nginx -t` без ошибок, nginx активен
- `curl http://127.0.0.1:8101/` → 200 с ответом от `shop backend`
