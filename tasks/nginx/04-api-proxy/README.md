# nginx-04 · Reverse proxy для API

**Уровень:** Middle · **Тема:** nginx / proxy · **Время:** ~20 мин

## Легенда
Фронт ходит в API через nginx: `http://127.0.0.1:8104/api/...` → бэкенд `api-backend`
(127.0.0.1:9104). Бэкенд ждёт пути **без** префикса `/api` (`/v1/users`, `/upload`) и для
аудита требует, чтобы прокси передавал реальный IP клиента в `X-Forwarded-For`.
Сейчас:
- `curl http://127.0.0.1:8104/api/v1/users` — ошибка;
- загрузка файла 2 МБ (`curl -X POST --data-binary @file http://127.0.0.1:8104/api/upload`) — ошибка.

## Задача
Настрой проксирование так, чтобы API работало.

## Ограничения
- Бэкенд не менять.
- Загрузки до 10 МБ должны проходить, больше — нет (лимит не снимать полностью).

## Критерии готовности (что проверяет check)
- `GET /api/v1/users` → 200
- `POST /api/upload` с телом 2 МБ → 200
- `POST /api/upload` с телом 11 МБ → 413
- бэкенд получает `X-Forwarded-For`
