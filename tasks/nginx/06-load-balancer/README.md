# nginx-06 · Балансировщик: 502 через раз и 504 на отчётах

**Уровень:** Middle · **Тема:** nginx / upstream, таймауты · **Время:** ~20 мин

## Легенда
nginx на порту **8106** балансирует магазин на три бэкенда: `shop-a` (9161), `shop-b` (9162),
`shop-c` (9163). Сервер `shop-c` сейчас в ремонте и выключен. Жалобы:
- примерно каждый третий запрос к сайту получает `502 Bad Gateway`;
- страница `/report` (отчёты строятся 6–8 секунд) всегда падает с `504 Gateway Timeout`.

## Задача
Настрой nginx так, чтобы пользователи не видели ошибок.

## Ограничения
- `shop-c` из upstream **не убирать**: после ремонта он должен вернуться в работу без правки конфига.
- Бэкенды не трогать.
- Увеличенный таймаут нужен только для `/report`, для остального сайта оставь как есть
  (зависший бэкенд не должен держать обычных пользователей).

## Критерии готовности (что проверяет check)
- 30 запросов подряд к `http://127.0.0.1:8106/` — все 200
- `GET /report` → 200
- `127.0.0.1:9163` остался в upstream, `nginx -t` OK
