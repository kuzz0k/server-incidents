# nginx-02 · nginx не стартует

**Уровень:** Junior · **Тема:** nginx / конфигурация · **Время:** ~10 мин

## Легенда
Безопасники добавили в nginx «харднинг» заголовков, а маркетинг одновременно попросил
поднять лендинг на порту 8102 (файлы в `/srv/www/landing`). После этого `systemctl restart nginx`
падает, и все сайты на сервере лежат.

## Задача
Подними nginx и лендинг на 8102.

## Ограничения
- Харднинг безопасников оставить: nginx не должен показывать версию в `Server`, а ответы должны содержать `X-Frame-Options`.
- Лендинг должен отдавать именно nginx.

## Критерии готовности (что проверяет check)
- `nginx -t` без ошибок, nginx активен
- `curl http://127.0.0.1:8102/` → 200, страница лендинга, ответ от nginx
- заголовок `Server` без версии, есть `X-Frame-Options`
