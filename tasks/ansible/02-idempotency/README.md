# ansible-02 · Сделать плейбук идемпотентным

**Уровень:** Junior/Middle · **Тема:** Ansible · **Время:** ~25 мин

## Легенда
Плейбук `/opt/trainer-ansible/base/base.yml` готовит сервер под приложение, но написан на
`shell`: на чистом сервере проходит, а при повторном запуске падает, плодит дубли строк в
конфигах и каждый раз показывает `changed`.

## Задача
Перепиши `base.yml` на модули Ansible так, чтобы результат был таким:
- группа `appusers`; пользователь `appuser` (основная группа `appusers`, shell `/bin/bash`, домашний каталог);
- каталог `/opt/app`, владелец `appuser:appusers`, права `0750`;
- в `/etc/motd` есть строка `Managed by Ansible` (ровно одна);
- файл `/etc/app/app.conf` содержит строку `log_level=info` (ровно одну), каталог `/etc/app` с правами `0755`.

Повторный запуск не должен ничего менять.

## Ограничения
- Без `shell`, `command`, `raw`.
- Только модули из `ansible.builtin` (коллекций на стенде нет).

## Критерии готовности (что проверяет check)
Check убирает созданное, запускает плейбук дважды и проверяет: оба прогона успешны, во втором
`changed=0`, итоговое состояние соответствует описанию, в плейбуке нет `shell`/`command`/`raw`.
