# mysql-01 · MariaDB: потерян пароль root, восстановить базу из дампа

**Уровень:** Middle · **Тема:** MySQL/MariaDB · **Время:** ~25 мин

## Легенда
Бывший админ перед уходом зачем-то сменил способ входа root в MariaDB на пароль, и пароль никто
не знает: `sudo mysql` больше не пускает. Тем временем база магазина `shop` пропала, остался
только ночной дамп в `/var/backups/mysql/`.

## Задача
1. Верни себе доступ: root должен снова входить **без пароля через unix-сокет** (`sudo mysql`).
2. Восстанови базу `shop` из дампа.
3. Создай пользователя приложения `shop@localhost` с паролем `Shop-Pass-2026` и правами только на `shop.*`.

## Ограничения
- Каталог данных MariaDB не удалять и не переинициализировать (там могут быть другие базы).
- После работы MariaDB должна работать в обычном режиме (без `--skip-grant-tables`).

## Критерии готовности (что проверяет check)
- `sudo mysql -e 'select 1'` работает без пароля
- в `shop` 500 клиентов и 2000 заказов
- `mysql -ushop -pShop-Pass-2026 shop` читает `orders`; у `shop` нет глобальных привилегий
- MariaDB запущена без `skip-grant-tables`
